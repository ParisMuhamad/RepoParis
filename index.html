Tutorial & Dokumentasi

Panduan Cara Mengganti Sources.list

1

Backup File Lama

Amankan file konfigurasi asli Anda sebelum melakukan modifikasi sistem.

sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
2

Edit File Konfigurasi

Buka editor terminal nano untuk menempelkan daftar mirror yang baru.

sudo nano /etc/apt/sources.list
3

Update & Upgrade

Sinkronkan database paket agar sistem siap mengunduh dari mirror baru.

sudo apt update && sudo apt upgrade -y
Contoh Konfigurasi sources.list (Ubuntu 26.04 Resolute) 
deb http://archive.ubuntu.com/ubuntu/ resolute main restricted universe multiverse
deb http://archive.ubuntu.com/ubuntu/ resolute-updates main restricted universe multiverse
deb http://archive.ubuntu.com/ubuntu/ resolute-security main restricted universe multiverse
